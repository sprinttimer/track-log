# Track Log v2.9.0

陸上トラック競技向けのオフライン優先PWAです。GitHub Pagesでは、このフォルダ内のファイルをリポジトリのルート直下へ配置してください。`icons` フォルダは不要で、アイコンPNGもルート直下に置く構成です。

## v2.9.0 の主な更新

- **練習メニューを使用実績から自動並び替え**。直近30日の使用回数を最優先し、同程度なら最近使ったメニュー、さらに総使用回数の順で上へ表示します。カスタムメニューはお気に入りを優先した上で使用実績も反映します。
- **同距離の「練習ベスト」**を公式PBとは別に自動管理。1本ずつ入力した場合は最速1本、平均入力の場合はその平均値を使います。NEW練習BESTは活動日誌にも表示します。
- **簡易コーチのコメントを大幅拡張**。PB速度比、同距離の練習ベスト、反復タイム低下、ばらつき、同種練習の頻度、走行量、練習前後の疲労、次の大会までの日数、年齢区分などを組み合わせて、客観的な文章を生成します。
- 1日に複数メニューを登録した場合も、距離構成・高負荷メニュー数・合計走行量・練習ベスト更新・疲労変化などから **その日全体のコメント** を再生成します。
- **試合結果コメント**を追加。PB/SB、PB速度比、同種目の前回レース、直近レースの中央値、風、試合前後の疲労、試合前7日の状態などを組み合わせます。
- **試合前分析**を強化。試合前3日・7日の走行量、高負荷日、休養日、疲労感を本人の通常値と比較します。
- **試合後分析**を追加。試合後の練習再開日、疲労感が通常域へ戻るまでの日数、2日以内の高負荷練習、疲労推移などを自動で追跡します。データが増えるたびに表示内容も更新されます。
- **活動日誌にキーワード検索**を追加。`300`、`ブロック`、`41.20`、大会名、メモなどを検索でき、複数キーワードはAND検索です。距離・各本タイム・メニュー名・大会名・メモ・簡易診断・試合コメントまで横断して検索します。
- 既存のv2.8以前の練習データも表示時に新しいロジックでコメントを再計算できるようにし、新規・編集保存データには `coachVersion: 2.9` を記録します。
- バックアップ形式を **version 7** に更新。従来バックアップの読み込み互換性は維持します。
- PWAビルドを **v290 / Service Worker r10** に更新。

## 既存の重要仕様

- 1日1記録の中に複数練習メニューを「＋」で追加可能。
- 活動日誌から練習を編集し、後からタイムを追記可能。編集後はその日の簡易診断と直近7日分析を再計算。
- 標準メニューの曖昧な「スピード」「その他」は削除済み。
- 「スピード持久」は「ロングスプリント（200〜400mなど）」へ整理。
- 「スターティングブロック」「フライング走（最高速度区間）」を区別。
- 練習画面ではRPE/PRE表記を使わず、練習前・練習後の疲労感を使用。試合側のRPEはレース記録として残します。
- スマートフォンだけでバックアップ保存・復元可能。復元は「置き換え」「追加」を選択可能。
- PWAアイコンはGitHubリポジトリのルート直下配置。
- オンライン時は `version.json` を `no-store` で確認し、Service Workerもネットワーク優先で最新版を確認。

## キーワード検索の例

- `300` → 300mを含む練習や試合
- `300 41.2` → 300mかつ41.2を含む記録
- `ブロック` → スターティングブロックを含む記録
- `県記録会` → 大会名・メモ等に含まれる記録

検索結果を開くと、その日の全メニューと簡易診断、試合の場合は結果コメント・試合前分析・試合後分析も確認できます。

## GitHub Pages への配置

ZIPを解凍し、中身を `track-log` リポジトリのルート直下へ上書きしてください。

主なファイル:

- `index.html`
- `app.js`
- `coach.js`
- `db.js`
- `styles.css`
- `manifest.webmanifest`
- `service-worker.js`
- `version.json`
- `.nojekyll`
- 各PNGアイコン / `favicon.ico`

`index.html` 単体ではPWAの全機能は動作しません。公開時はZIP内のファイル一式を同じ階層へ配置してください。
