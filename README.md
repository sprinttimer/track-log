# Track Log PWA v2.6.0

## v2.6.0 の主な変更

- 練習タイムを完全な任意項目へ変更。短距離・スタート練習などでタイムを測っていなくても保存できます。
- タイム未入力をマイナス評価しません。速度評価・PB比・反復タイム低下だけを省略します。
- 日次総評は距離 × 本数 × セットの総走行量、RPE、練習前後の疲労感、メニュー種別、過去の同メニュー量から判定します。
- 過去データが3件以上ある同メニューは、その人自身の通常量と比較して「多め / 通常範囲 / 量を抑えた構成」をコメントします。
- 週間分析と試合前3日・7日分析もタイム未計測日を無視しません。タイムがある日はPB比、タイムがない日はメニュー特性とRPEを補助指標として高負荷セッションを判定します。
- 試合前の期間表記は「試合前3日」「試合前7日」「試合前コンディション分析」に統一し、分かりにくい略語を画面から除外しています。
- スターティングブロック、フライング走（最高速度区間）、ウェイト専用フォーム、カスタムメニュー、前後疲労感、試合機能、PWAアイコン対策などv2.5までの機能は維持しています。
- オンライン時Network First + `cache: no-store` + `version.json` による最新版確認を維持しています。

## GitHub Pagesへの反映

ZIPを解凍し、中身をすべて `track-log` リポジトリ直下へ上書きしてください。`index.html` だけでなく `app.js`、`coach.js`、`service-worker.js`、`version.json`、`manifest.webmanifest` も必ず更新してください。

アイコン類は引き続きリポジトリ直下配置です。既存のホーム画面ショートカットで古いアイコンが残る場合は、ショートカットを削除してから最新版ページを開き直し、再度ホーム画面へ追加してください。
