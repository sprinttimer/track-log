# Track Log v3.2.0

陸上競技向けのオフライン優先トレーニング日誌PWAです。v3.2では、v3.1までの全機能を維持しながら「シーズンベスト」ページを追加しました。

## v3.2 の主な追加

- ホーム画面に「今季ベスト」カードを追加
- 活動日誌から「ベスト記録」ページへ移動可能
- 保存済みの日誌から「距離別 練習シーズンベスト」を自動集計
- 複数本の練習は、その日の最速1本を距離別SBの候補として使用
- フライング走は通常の距離別SBに混ぜず、計測距離＋助走距離ごとに別枠集計
- 保存済みの試合結果から「公認試合 シーズンベスト」を種目別に自動集計
- 100m / 200m / 100mH / 110mH は風速 +2.0m/s 以内かつ風速入力済みの公認記録のみ対象
- 「公認記録としてPB判定」がOFFの試合は公認SBから除外
- 年度セレクターで過年度のSBも確認可能
- 各SB行をタップすると、その記録を出した日の活動日誌へ直接ジャンプ
- ジャンプ先を一時的にハイライトして見つけやすく表示

## v3.1までの主要機能

- 1日複数メニューをまとめて保存
- 活動日誌から編集し、後からタイム追加入力
- 編集後に簡易診断・直近7日分析を再計算
- 使用頻度＋最近使用した順で練習メニューを自動並び替え
- 公式PBと別に「練習ベスト」を管理
- 短距離・中距離・長距離・ハードル向け標準メニュー
- ペース走 / インターバル走 / ジョグ / ロング走などで分:秒・時:分:秒入力
- 月間カレンダーと一覧表示の切替
- 距離・タイム・大会名・メモ・コメントを横断するキーワード検索
- 同一メニューの過去比較＋折れ線グラフ
- 練習コメント、試合結果コメント、試合前後分析
- ウェイト、カスタムメニュー、入力プリセット
- JSONバックアップ / 置き換え復元 / 追加復元
- CSVエクスポート
- PWA、ホーム画面追加、Service Worker、オンライン時の最新版確認

## シーズンベストの考え方

練習SBは、同じ距離の保存済み練習からシーズン中の最速タイムを自動集計します。公式試合SBとは分離しています。フライング走は助走条件でタイムの意味が変わるため、通常SBとは別枠です。

公認試合SBは試合結果のうち公認条件を満たすものだけを対象にします。風力対象種目は +2.0m/s を超える記録、または風速未入力の記録を公認SBから除外します。

## CSVについて

CSVには日付、活動種別、メニュー名、距離、本数、セット、平均/最速/各本タイム、平均ペース、レスト、ウェイト、カスタム値、疲労感、大会情報、風、PB/SB、RPE、メモ、自動コメントなどを書き出します。

CSVはデータ復元用ではありません。機種変更や完全復元には「バックアップを保存」で作成するJSONファイルを使用してください。
