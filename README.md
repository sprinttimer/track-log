# Track Log v2.7.0

陸上トラック競技向けのオフライン優先PWAです。GitHub PagesなどのHTTPS環境へ、このフォルダの中身をそのままリポジトリ直下へ配置してください。

## v2.7.0 の主な更新

- **1日1記録・複数メニュー方式**に変更。練習入力で「＋ この練習内容を追加」を押すと、ランニング・ウェイト・カスタムを同じ日の中へ順番に追加できます。最後に練習前/後の疲労感、練習時間、メモを共通情報として一度だけ入力し、「この日の練習をまとめて保存」で保存します。
- 簡易コーチは追加されたメニューを個別の日として扱わず、**その日の練習全体**として走行量、高負荷メニュー、PB速度比、反復低下、前後疲労、大会までの日数をまとめて評価します。
- 標準メニューから曖昧な「スピード」と「その他」を削除。旧記録は「旧メニュー」として閲覧できますが、新規入力には表示しません。
- 「スピード持久」を **「ロングスプリント（200〜400mなど）」** に変更。200/250/300/350/400mなどを例示しつつ、距離だけで負荷を断定しない説明を表示します。
- 「フライング走（最高速度区間）」と「スターティングブロック」を維持。フライング走は助走距離と計測距離を分けて記録できます。
- 練習画面の曖昧だった負荷入力（RPE）は削除し、**練習前・練習後の疲労感**へ整理しました。試合前分析は **「試合前コンディション分析」「直前3日・7日」** と日本語表示に統一しています。
- **スマートフォンだけでバックアップ・機種変更**できる案内を設定画面へ追加。「バックアップを保存」→ Google Drive / iCloud Drive / ファイル等へ保存 → 新端末で復元、の3手順を画面内に表示します。
- 復元は **「この端末のデータを置き換える」** と **「現在のデータに追加する」** の2方式。追加復元では同名設定・同一記録の重複をできるだけ避けます。
- モバイルでWeb Share APIのファイル共有に対応している場合は共有/保存画面を優先し、未対応環境ではJSONファイルをダウンロードします。
- タイム未計測の練習も保存可能。距離・本数・セット・前後の疲労感から分析し、未計測を低パフォーマンスとは判定しません。
- PWAアイコンは不具合対策済みの**リポジトリ直下配置**を継続。Service Workerはオンライン時Network First + `no-store`、`version.json`による最新版確認、`updateViaCache: none`を使用します。

## GitHub Pages へ更新する場合

ZIPを解凍し、このフォルダ内のファイルを `track-log` リポジトリの **ルート直下**へ上書きしてください。`icons/` フォルダは作成不要です。`icon-192-v240.png` などのアイコンもルート直下に置きます。

既にホーム画面へ追加している端末は、オンライン時に最新版を確認します。OSが古いアイコン自体を保持している場合のみ、旧ショートカットを削除してページを再読み込み後、ホーム画面へ追加し直してください。

## バックアップ対象

プロフィール、自己ベスト、カスタムメニュー、入力プリセット、ウェイト種目、練習記録（1日複数メニューを含む）、大会予定・試合結果をJSONへ保存します。ブラウザの保存領域保護はバックアップの代替ではないため、機種変更前にはバックアップファイルを保存してください。
