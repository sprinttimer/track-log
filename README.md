# Track Log v3.1.0

陸上競技向けのオフライン優先トレーニング日誌PWAです。v3.1では、v3.0までの機能を維持したまま「同一メニューの過去比較＋グラフ」と「CSVエクスポート」を追加しました。

## v3.1 の主な追加

- 活動日誌の各練習メニューに「推移 / 過去比較」ボタンを追加
- ランニングは同じメニュー分類＋同じ距離の記録を自動抽出
- 本数・セット・助走条件が同じ記録を「同条件」として前回比較に優先
- 今回 / 前回（同条件優先） / 直近5回平均 / 練習BEST を表示
- 直近最大12件を折れ線グラフで表示。タイム系は「上ほど速い」表示
- ウェイトは同一種目の総ボリューム推移を参考表示
- カスタムメニューは同一メニューの代表値推移を、設定した評価方向に従って表示
- 設定 → バックアップ・機種変更の中に「CSVで書き出す」を追加
- CSVはUTF-8 BOM付きで、Excel / Googleスプレッドシートで扱いやすい形式
- 練習は1メニュー1行、試合は1レース1行で出力
- JSONバックアップは従来どおり完全復元用、CSVは閲覧・分析用として役割を分離

## v3.0までの主要機能

- 1日複数メニューをまとめて保存
- 活動日誌から編集し、後からタイム追加入力
- 編集後に簡易診断・直近7日分析を再計算
- 使用頻度＋最近使用した順で練習メニューを自動並び替え
- 公式PBと別に「練習ベスト」を管理
- 短距離・中距離・長距離・ハードル向け標準メニュー
- ペース走 / インターバル走 / ジョグ / ロング走などで分:秒・時:分:秒入力
- 月間カレンダーと一覧表示の切替
- 距離・タイム・大会名・メモ・コメントを横断するキーワード検索
- 練習コメント、試合結果コメント、試合前後分析
- ウェイト、カスタムメニュー、入力プリセット
- JSONバックアップ / 置き換え復元 / 追加復元
- PWA、ホーム画面追加、Service Worker、オンライン時の最新版確認

## CSVについて

CSVには日付、活動種別、メニュー名、距離、本数、セット、平均/最速/各本タイム、平均ペース、レスト、ウェイト、カスタム値、疲労感、大会情報、風、PB/SB、RPE、メモ、自動コメントなどを書き出します。

CSVはデータ復元用ではありません。機種変更や完全復元には「バックアップを保存」で作成するJSONファイルを使用してください。
