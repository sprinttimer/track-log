# Track Log v2.8.0

陸上トラック競技向けのオフライン優先PWAです。GitHub Pagesでは、このフォルダ内のファイルをリポジトリのルート直下へ配置してください。`icons` フォルダは不要で、アイコンPNGもルート直下に置く構成です。

## v2.8.0 の主な更新

- 活動日誌の練習記録に **「編集」ボタン**を追加。
- 練習場ではタイム未入力のまま保存し、自宅などで後からタイム・本数・セット・メニュー・疲労感・メモを追記/修正可能。
- 1日の複数メニューを編集画面へそのまま復元。
- 追加済み各メニューにも **「編集」** を追加。既存メニューを削除・作り直さずタイムだけ追記できる。
- 「タイム未入力」を活動日誌で明示。
- 編集保存時は既存記録IDを維持し、新規記録として二重登録しない。
- 編集内容から **簡易診断を完全再計算**。タイム追加時はPB速度比・反復タイム低下などを新たに反映。
- 編集後はホームの直近7日分析、高負荷日、走行量、疲労傾向も再集計。
- タイム未入力時の簡易診断には「距離・本数・セット・疲労を中心に判定中」であることを明示し、後からタイム追加すると診断が変わることを案内。
- バックアップ形式を version 6 に更新（従来データもそのまま読み込み可能）。
- PWAビルドを v280 / Service Worker r9 に更新。

## v2.7 までに反映済みの重要仕様

- 1日1記録の中に複数練習メニューを「＋」で追加可能。
- 標準メニューの曖昧な「スピード」「その他」を削除。
- 「スピード持久」は「ロングスプリント（200〜400mなど）」へ整理。
- 「スターティングブロック」「フライング走（最高速度区間）」を分かりやすく区別。
- 練習のRPE/PRE表記を廃止し、練習前・練習後の疲労感を使用。
- スマートフォンだけでバックアップ保存・復元が可能。
- 復元時は「端末データを置き換える」「現在のデータに追加する」を選択可能。
- PWAアイコンはGitHubリポジトリのルート直下配置。
- オンライン時は `version.json` を no-store で確認し、Service Worker もネットワーク優先で最新版を確認。

## GitHub Pages への配置

ZIPを解凍し、中身を `track-log` リポジトリのルート直下へ上書きしてください。

主なファイル:

- `index.html`
- `app.js`
- `coach.js`
- `db.js`
- `styles.css`
- `manifest.webmanifest`
- `service-worker.js`
- `version.json`
- `.nojekyll`
- 各PNGアイコン / `favicon.ico`

## 活動日誌の編集方法

1. 下部メニューの「日誌」を開く。
2. 編集したい練習日の「編集」を押す。
3. 追加済みメニューの「編集」を押す。
4. タイムなどを追記・修正する。
5. 「この練習内容を更新」を押す（そのまま最下部の保存でも更新内容を反映可能）。
6. 「編集内容を保存して診断を更新」を押す。

保存後は、その日の簡易診断と直近7日分析が最新データから再計算されます。
