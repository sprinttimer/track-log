# Track Log PWA v2.3.0

陸上トラック競技向けのオフライン優先・個人用トレーニング／試合ログです。外部API・外部ライブラリは使用していません。

## v2.3 の主な変更

- 活動タイプを「練習 / 試合」に分離。
- 大会予定から「結果を入力」へ連携。大会名・種目・ラウンド・記録・順位・風速・前後疲労・RPEを保存。
- 公認条件を満たす場合のPB自動更新。100m/200m/100mH/110mHは風速 +2.0m/s超を追い風参考としてPB自動更新から除外。風速未入力も自動PB更新しない安全側の仕様。
- 試合前3日・7日の標準ランニング量、高強度回数、休養日、練習前疲労、通常週との比較を自動コメント。
- ホームの「直近7日 総合コメント」は直近7日とその前28日を比較。標準ランニングの走行量・高強度回数、前疲労、RPE、練習時間×RPEを組み合わせて多数の文面パターンから表示。
- ウェイトをランニング入力から完全分離。重量 / rep / set / 総ボリュームを記録。設定画面で使用種目をユーザー登録・お気に入り化。
- カスタムメニューは「小さいほど高評価 / 大きいほど高評価」を任意設定。時間・距離・回数・重量・その他の単位に対応。
- カスタム/ウェイトのメニュー内容は簡易コーチ評価対象外。ただし前後疲労・RPE・入力済み練習時間は本人のコンディション情報として全体傾向に利用。
- タイム欄は `12.34` だけでなく `1:52.40` 形式にも対応。
- PWAアイコンを作り直し、any 192/512 と maskable 192/512 を分離。Android用maskableは安全領域内に図案を収め、Apple Touch Icon / faviconも専用生成。
- manifest の `id` / `start_url` / `scope` をGitHub Pagesのリポジトリ相対パスで統一。
- 設定画面にPWA診断（HTTPS / Service Worker / アイコン読込 / standalone起動）を追加。
- オンライン時は Service Worker を Network First + `cache:no-store`。`version.json` は起動・画面復帰・オンライン復帰・30分ごとにキャッシュを使わず確認。オフライン時のみキャッシュへフォールバック。

## GitHub Pages への配置

ZIPを解凍し、中のファイルと `icons` フォルダをリポジトリ直下へアップロードしてください。ZIPファイル自体を置くのではありません。

最低限、次がリポジトリ直下に見える状態にします。

- index.html
- app.js
- coach.js
- db.js
- styles.css
- manifest.webmanifest
- service-worker.js
- version.json
- .nojekyll
- icons/

GitHub の `Settings > Pages` で `Deploy from a branch`、`main`、`/(root)` を選択します。

## ホーム画面アイコンを更新する場合

OS/ブラウザは既存ショートカットのアイコンを保持することがあります。旧バージョンがホーム画面に残っている場合は、**アプリ内データを消さず、ホーム画面の古いショートカットだけ削除**し、ブラウザで最新版を再読み込みしてから再インストールしてください。

設定画面の「ホーム画面・ブックマーク」に、PWAアイコンが実際に読めているかを確認する診断表示があります。

## 保存データ

IndexedDBを使用します。プロフィール、練習、試合、カスタムメニュー、ウェイト種目、入力プリセットは端末内保存です。JSONバックアップを定期的に保存してください。
