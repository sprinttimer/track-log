# Track Log v3.0.0

陸上競技向けのオフライン優先PWAです。練習・試合・疲労感・自己ベスト・大会予定を端末内に保存し、簡易コーチコメント、検索、バックアップ／復元を利用できます。

## v3.0.0 の主な更新

### 1. 分・秒のタイム入力を強化
- 短距離は `12.34` のような秒入力をそのまま利用できます。
- 長距離・ジョグ・レースは `3:20`、`25:00`、`1:02:30` の形式に対応しています。
- スマートフォンのキーボードで `:` が出しにくい場合に備え、各タイム入力欄に **「:」ボタン**を追加しました。
- 本間レスト・セット間レストも `1:30` などの分:秒入力に対応しています。数字だけを入力した場合は従来どおり「分」として扱います。
- ジョグ／ロング走は距離が分からなくても所要時間だけで保存できます。
- 距離とタイムがある場合は平均ペース（/km）を自動表示します。

### 2. 長距離系の標準メニューを拡充
- **ペース走（一定ペース）**
- **インターバル走**
- 既存のレペティション、ロング走・LSD、ビルドアップ、テンポ走、ジョグと合わせて記録できます。
- 短距離／ハードル設定でもペース走・インターバル走を選べるようにし、専門外の補助練習も記録できます。
- 簡易コーチでは平均ペース、反復のばらつき、後半低下、レスト、前後疲労を組み合わせてコメントします。

### 3. 活動日誌に月間カレンダーを追加
活動日誌の上部で **「一覧 / カレンダー」** を切り替えられます。

カレンダーでは月単位で、
- ランニング
- ウェイト
- カスタム
- 試合

を色付きドットで確認できます。日付をタップすると、その日の記録と簡易診断・レース分析を表示します。

既存の一覧表示は削除していません。キーワード検索や「ランニング / ウェイト / カスタム / 試合」のフィルターは一覧・カレンダーの両方に反映されます。

### 4. 既存機能を維持
- 1日に複数メニューをまとめて登録
- 活動日誌から後日編集・タイム追加入力
- 編集後に簡易診断・直近7日分析を再計算
- よく使うメニューの自動上位表示
- 公式PBとは別の練習ベスト
- 試合結果コメント、試合前・試合後分析
- 複数キーワードによる活動日誌検索
- スマートフォンでのJSONバックアップ／復元
- PWAホーム画面追加
- オンライン時の最新版確認、オフライン時のキャッシュ利用

## GitHub Pages への配置
ZIPを解凍し、**中のファイルをすべてリポジトリのルート直下**へ配置してください。`icons` フォルダは不要です。アイコンPNGもルート直下に置く構成を維持しています。

主なファイル:
- `index.html`
- `styles.css`
- `app.js`
- `coach.js`
- `db.js`
- `manifest.webmanifest`
- `service-worker.js`
- `version.json`
- `.nojekyll`
- 各種アイコンPNG / favicon

## データ互換性
IndexedDB名は従来の `track-coach-log` を維持しているため、同一オリジン上でv2.xから更新した場合も既存記録をそのまま利用する設計です。バックアップ形式も旧記録を読み込めるよう、既存フィールドを残しながら新しい `restSeconds` 等を追加しています。
