# Track Log PWA v2.1.0

陸上トラック競技に特化した、端末内保存型の練習日誌 + パフォーマンス記録 + ルールベース簡易コーチです。

## 今回追加・強化した内容
- 最新版確認を最優先：全アプリ資産は Network First + `cache: no-store`
- `version.json?ts=...` を起動時・オンライン復帰時・画面復帰時・30分ごとに確認
- Service Worker は `updateViaCache: none` + 新版即時有効化
- オフライン時だけ最後に取得したキャッシュへフォールバック
- PWAホーム画面追加導線、iOS/Android/PC別ブックマーク案内、URLコピー
- 最終決定した Track Log アイコンを PWA / Apple Touch / 起動画面 / ヘッダーに反映
- 標準メニュー用「よく使う入力プリセット」
- ユーザー独自「カスタム練習メニュー」
- カスタム測定タイプ：タイム（秒、小さいほど良い） / 距離（m、大きいほど良い）
- カスタム基準値に対するパフォーマンス ±％
- カスタムは履歴保存・比較は行うが、簡易コーチ評価から明確に除外
- お気に入りプリセット / カスタムメニューを ★ で上位表示
- IndexedDB、JSONバックアップ/復元、Storage Persistence要求

## 重要：キャッシュ更新方針
オンライン時は古いキャッシュを優先しません。HTML/JS/CSS/manifest等はネットワーク取得を先に試し、失敗時だけキャッシュを使います。
さらに `version.json` に毎回一意のクエリを付けて最新バージョンを確認します。

公開版を更新する際は次の3つを同じ新バージョンへ変更してください。
1. `app.js` の `APP_VERSION`
2. `version.json` の `version`
3. `service-worker.js` の `CACHE_NAME`

また、HTML内の `?v=...` も更新すると静的アセットのURL自体が変わり、より確実です。

## ブックマークについて
Webページ側からブラウザのブックマーク登録UIを強制表示する標準APIはありません。本アプリは、端末別手順の表示とPWAインストール導線を実装しています。

## カスタムメニューの評価
カスタムメニューは学校・地域・団体独自の内容を想定しており、アプリ側に負荷特性の定義がありません。そのためパフォーマンス比較・履歴保存は行いますが、簡易コーチの総合評価には使用しません。
